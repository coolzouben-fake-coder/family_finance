# 第一版手工验收

数据库规则依据：[CloudBase 安全规则 - 仅管理员可读写](https://docs.cloudbase.net/rule/rule-example)。官方说明中，`read: false`、`write: false` 会拒绝普通客户端访问，但云函数和控制台仍可通过管理端身份操作。

- [ ] 使用微信开发者工具打开项目，确认云开发环境 ID 已配置。
- [ ] 在云开发控制台依次打开 `users`、`family_assets`、`asset_changes`、`categories`、`projects`、`settings` 集合的“权限管理”，切换到安全规则，并为每个集合应用仓库根目录 `database.rules.json`（`read: false`、`write: false`）。不要把 sitemap 规则误用为数据库规则。
- [ ] 保存每个集合的规则后重新打开权限配置，确认仍为拒绝客户端读写；云函数使用管理端身份访问，不受该客户端规则限制。
- [ ] 在开发者工具控制台使用小程序端 `wx.cloud.database()` 对上述每个集合发起读取和新增测试，确认客户端直接读取和写入均被拒绝（预期 `DATABASE_PERMISSION_DENIED`），测试数据未落库。
- [ ] 部署 `bootstrap` 云函数并确认 `categories` 中包含“羊毛”。
- [ ] 部署 `login`、`assets`、`projects`、`stats` 云函数。
- [ ] 在数据库客户端直连被拒绝后，通过已部署云函数完成登录、读取资产、创建项目和读取统计，确认云函数授权路径正常。
- [ ] 在 `users` 集合中加入两位家庭成员的 `openid`，并设置 `enabled: true`。
- [ ] 设置家庭总资产为 `50000`，首页显示空闲资金 `50000`。
- [ ] 新增 28 天、3% 年化、固定奖励 200、本金 10000 的理财项目。
- [ ] 新增项目时将登记人切换为第二位家庭成员，保存后确认列表和统计页均显示该成员。
- [ ] 首页当前理财金额增加 `10000`，资金利用率显示 `20.0%`。
- [ ] 项目到期前 3 天内出现在“即将到期”区域。
- [ ] 项目过期未确认时出现在“已到期待确认”区域。
- [ ] 确认到账后填写实际利息 `23.01`、实际固定奖励 `200`。
- [ ] 打开已到账项目，将到账日期、实际利息和实际固定奖励更正后保存，确认项目和受影响年度统计同步更新且基础信息仍不可编辑。
- [ ] 首页当前理财金额减少 `10000`，统计页年度总收益显示 `223.01`。
- [ ] 在项目列表分别按状态、品类、登记人和年份筛选，确认结果与组合筛选条件一致，清空筛选后恢复全部项目。
- [ ] 对未到账项目执行取消并确认其不再占用资金；对可删除项目执行删除并确认记录消失，两个确认弹窗选择放弃时均不得改变数据。
- [ ] 在统计页切换年度，确认月度收益、品类收益金额及占比、实际利息与实际固定奖励金额及占比、登记人收益及年化均匹配到账项目。
- [ ] 分别模拟登录、首页资产/项目、项目表单品类/成员/项目、项目列表和统计云函数失败，确认页面显示错误状态，编辑与保存入口不可用，且不会写入空值或默认值。
- [ ] 非白名单微信账号打开小程序时进入“无访问权限”页面。
