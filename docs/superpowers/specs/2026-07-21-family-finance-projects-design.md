# 家庭理财项目状态与收益台账设计

## 背景

本小程序用于家庭两人共同记录理财项目状态、资金占用和收益情况。它不是完整记账软件，也不是实时行情或投资交易工具；第一版重点是把每个有周期的理财项目记录清楚，并汇总当前家庭资金利用情况和历史收益。

项目采用原生微信小程序和微信云开发，满足家庭自用、低成本、白名单访问、无需自建服务器的约束。

## 目标

- 记录每个理财项目的本金、起止时间、品类、登记人、预期收益和实际收益。
- 根据家庭总资产统计当前理财总金额、空闲资金和资金利用率。
- 支持项目到期后的手动确认到账，确保资金释放和收益入账口径准确。
- 按年度、月份、品类、登记人分析实际收益。
- 区分利息类收益和固定奖励，支持类似“28 天 3% 年化 + 200 固定收益”的项目。
- 只允许白名单中的两位家庭成员访问。

## 非目标

- 第一版不做完整账户体系，不记录银行卡、支付宝、券商等账户余额明细。
- 第一版不接实时行情、不自动同步银行或基金数据。
- 第一版不接微信支付、不购买服务器、不使用第三方付费服务。
- 第一版不做微信订阅消息提醒，只在首页和列表中展示到期提醒；订阅消息作为后续扩展。
- 浮动收益类项目只预留扩展空间，第一版主流程以到期或赎回后一次性确认收益为主。

## 核心范围

第一版采用“家庭资金看板 + 理财项目台账”的范围。

### 首页看板

首页用于回答“现在家庭资金在哪里”。

- 展示当前家庭总资产，并提供编辑入口。
- 展示当前理财总金额。
- 展示空闲资金。
- 展示资金利用率。
- 展示即将到期项目。
- 展示已到期待确认项目。

当前理财总金额只统计未确认赎回或到账、且未取消的项目本金。项目到期并不自动释放本金，必须手动确认到账后才从当前理财总金额中移除。

### 项目列表

项目列表用于日常管理理财项目。

- 默认按状态或结束日期排序，优先展示需要处理的项目。
- 支持按状态、品类、登记人、年份筛选。
- 列表项展示项目名称、本金、起止日期、预期总收益、实际总收益、实际年化收益率和状态。

### 项目表单

项目表单用于新增和编辑理财项目。

- 基本信息：项目名称、品类、登记人、备注。
- 投入信息：本金、开始日期、结束日期、预期年化收益率。
- 奖励信息：固定奖励。
- 到账信息：到账日期、实际利息收益、实际固定奖励。该部分在确认到账或编辑已到账项目时展示。

新增项目时，登记人默认取当前登录用户，也允许选择另一位家庭成员。

### 统计页

统计页用于回答“赚了多少、从哪里赚的”。

- 支持年度筛选。
- 展示年度总收益。
- 展示年度实际年化概览。
- 展示月度收益趋势。
- 展示品类收益占比。
- 展示利息收益与固定奖励拆分。
- 展示按登记人汇总的收益情况。

## 关键概念

### 家庭总资产

家庭总资产是一个可随时编辑的当前值。用户可能因为工资、奖金、支出、转账等原因调整该值。

每次编辑家庭总资产时，应保存变更记录，包括：

- 变更前金额。
- 变更后金额。
- 变更原因。
- 操作人。
- 操作时间。

空闲资金按当前家庭总资产计算，不依赖历史资产快照。

### 理财项目

理财项目是本小程序的核心记录对象。每个项目有明确的开始日期、结束日期、本金、收益预期和到账确认。

项目属于家庭整体资金池，不再设计资金归属字段。登记人只表示是谁录入或负责该项目，可用于筛选和统计，不影响家庭资金计算。

### 品类

第一版提供内置品类，并允许后续补充自定义品类。

内置品类：

- 银行理财
- 定期存款
- 基金
- 债券
- 券商理财
- 货币基金
- 羊毛
- 活动奖励
- 其他

### 状态

状态由系统日期判断和人工确认共同决定。

系统日期状态：

- 未开始：当前日期早于开始日期。
- 进行中：开始日期小于等于当前日期，且当前日期小于等于结束日期。
- 即将到期：距离结束日期不超过提醒天数，第一版默认 3 天。
- 已到期待确认：当前日期晚于结束日期，但尚未确认赎回或到账。

状态展示优先级为：已取消 > 已到账 > 已到期待确认 > 即将到期 > 进行中 > 未开始。即将到期是进行中的特殊展示状态，同一项目在界面上只展示一个主状态。

人工确认状态：

- 未到账：本金仍计入当前理财总金额。
- 已到账：本金从当前理财总金额释放，实际收益进入统计。
- 已取消：不计入当前理财金额，也不计入收益统计。

## 统计口径

### 预期收益

预期利息收益按以下公式计算：

```text
预期利息收益 = 本金 × 预期年化收益率 × 持有天数 / 365
```

预期持有天数按开始日期和结束日期包含首尾计算：

```text
预期持有天数 = 结束日期 - 开始日期 + 1
```

项目预期总收益：

```text
项目预期总收益 = 预期利息收益 + 固定奖励
```

### 实际收益

实际总收益：

```text
实际总收益 = 实际利息收益 + 实际固定奖励
```

实际持有天数：

```text
实际持有天数 = 赎回/到账日期 - 开始日期 + 1
```

示例：7 月 1 日开始，7 月 28 日到账，实际持有天数为 28 天。

实际年化收益率：

```text
实际年化收益率 = 实际总收益 / 本金 / 实际持有天数 × 365
```

实际年化收益率由系统自动计算，不作为手动录入字段。

### 资金统计

当前理财总金额：

```text
所有未到账且未取消项目的本金合计
```

空闲资金：

```text
当前家庭总资产 - 当前理财总金额
```

资金利用率：

```text
当前理财总金额 / 当前家庭总资产
```

### 收益统计

年度收益：

```text
赎回/到账日期在该年度内的实际总收益合计
```

月度收益趋势：

```text
按赎回/到账月份聚合实际总收益
```

品类收益占比：

```text
按项目品类聚合实际总收益
```

固定奖励占比：

```text
实际固定奖励 / 实际总收益
```

按登记人汇总：

```text
按登记人聚合项目数量、本金、实际总收益和实际年化收益率
```

年度实际年化概览不直接对项目年化做算术平均，避免短期高收益项目放大结果。第一版按已到账项目的总收益和加权本金天数计算：

```text
年度实际年化 = 年度实际总收益 / Σ(本金 × 实际持有天数) × 365
```

- `name`

## 权限设计

- 小程序启动后获取当前用户 `openid`。
- 查询 `users` 集合确认是否在白名单且 `enabled = true`。
- 非白名单用户只展示无访问权限页面。
- 所有数据读写都应在权限校验后进行。
- 云函数和数据库规则都应限制非白名单用户访问家庭数据。

## 错误处理

- 家庭总资产为空时，首页提示先设置总资产，资金利用率不展示或显示为 0。
- 家庭总资产小于当前理财总金额时，允许保存，但首页展示空闲资金为负数，并提示资产值可能需要更新。
- 本金必须大于 0。
- 结束日期不能早于开始日期。
- 确认到账时必须填写到账日期，到账日期不能早于开始日期。
- 实际年化收益率仅在本金大于 0 且实际持有天数大于 0 时计算。
- 编辑已到账项目的到账日期或实际收益时，需要提示会影响历史统计。
- 删除项目需要二次确认；第一版可物理删除，后续可扩展软删除。
